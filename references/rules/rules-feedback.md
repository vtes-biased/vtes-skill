# VTES Rules: Gaps & Inconsistencies

## Cross-document Contradictions

**1. New card legality timing (major)**
Tournament Rules 2.1 says new cards/rules go "immediately into effect." TR 4.3 says new cards allowed in Constructed "30 days after retail release." Contradiction. Likely intent: rules immediate, cards have 30-day Constructed wait (immediate in Limited), but 2.1 conflates both.

**2. Rating formula example error (Appendix A.2.1)**
Text says "in a qualifier with 50 players" but adds +0.25 (national championship bonus). Qualifiers get no coefficient bonus. Label should say "national championship" or +0.25 shouldn't be there. Math itself is correct (2.889 - 1 + 0.25 = 2.139).

**3. Infinite loop rule misplaced**
TR 4.9 defines the infinite loop rule but game rules never mention it. Casual play has no official infinite loop rule.

## Game Rules Internal Issues

**4. Placeholder text**: Line 557: `"<INSERT POLITICAL ACTION ICON>"` never replaced.

**5. Default bleed for allies undefined**: Rules say vampires have bleed 1. Allies can bleed but no default stated. Imbued appendix explicitly states "1 bleed" — implying regular allies may lack a default.

**6. Default strength for allies undefined**: Vampires default strength 1. No general ally default. Imbued appendix had to explicitly state "1 strength."

**7. Negative bleed amounts unaddressed**: Card effects can reduce bleed. If bleed < 0, does target gain pool? Floored at 0? Not specified.

**8. Burn option icon — ambiguous grammar**: Unlock phase advanced rules: Methuselah "who does not control a minion who meets the requirements of this card or is not a legal target" may discard. Unclear what "is not a legal target" modifies.

**9. "During X, do Y" template scope**: Only one Y per X "with this card." Two copies of same card in play — can each trigger once? Per-card restriction doesn't address multiple copies.

**10. Pronoun inconsistency**: Switches between "they/their" and "his/her"/"he or she" without consistency.

**11. Game end never explicitly stated**: No statement like "game ends when one Methuselah remains." Only inferable from oust/prey mechanics and VP glossary entry.

**12. Ally "as a vampire" capacity scope unclear**: Ally acting as vampire has capacity 1 "for use if card requires older vampire or given capacity." Other capacity-referencing effects (non-requirement) — do they see capacity 1? Ambiguous.

## Tournament Rules Internal Issues

**13. Duplicate sections 3.2 and 3.4**: Both titled "Pre-Game Procedure." 3.4 restates 3.2. Editing oversight.

**14. Concession requires group agreement**: TR 3.5: "all but one players agree to concede." Single player cannot unilaterally concede. Unusual constraint vs. most card games.

**15. Round end timing ambiguous at phase boundaries**: TR 3.1.1: Game ends with current minion action or at end of current phase. What if notification is between phases? Does player get discard phase if time called during influence phase?

**16. Finals with fewer than 5 qualifiers**: TR 3.1.3 assumes 5 finalists. No procedure for dropouts (4-person final).

**17. Late arrival scoring**: TR 3.3.1 allows late arrivals but doesn't specify scoring for missed rounds (0 GW/VP/TP?).

**18. Multi-deck tracking**: TR 3.1.5 allows multiple decks but no mechanism to track which deck per round. Matters for "Best-Performing Deck" finals method (3.1.5a).

**19. Play-to-win omits TP**: TR 4.8 says maximize GW then VP. TP is a tiebreaker (3.7.3) but not mentioned in play-to-win.

**20. "Sufficiently randomized" undefined**: TR 3.2/3.4 require it with no definition.

**21. Tiebreakers stop at top 5**: TR 3.1 breaks ties for "top five rankings" only. 6th+ unaddressed.

**22. 4-player table TP disadvantage**: TR 3.7.3: Empty seat gets 3rd place TP. Second-best player at 4-player table jumps from 2nd to 4th in TP (24 vs 48). Acknowledged but not compensated.
