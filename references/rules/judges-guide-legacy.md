# VEKN Judges' Guide
Effective 2004-01-01. All penalties assume unintentional infraction unless noted. Intentional infractions: upgrade penalty (see 1.6 Cheating). Judges may modify penalties for extenuating circumstances.

## 0.2 Penalty Levels
- **Caution**: Verbal warning, report to head judge, no paper tracking
- **Warning**: Officially tracked in VEKN Penalty Database, communicated to head judge + player
- **Game Loss**: Warning always included. Between games: applied to next game. Mid-game: judge awards pool/VPs to predator or makes arrangements for game balance (partial VPs possible). Recorded as loss to all active players, tied with other game-loss players
- **Disqualification**: Warning always included. Player loses current match, dropped from tournament. Prizes earned before DQ still received. **DQ without Prize**: no prizes, no professional points, no event invitations. Recommended for severe unsportsmanlike conduct and cheating

## 0.4 Repeat Offenses
Escalation: Caution -> Warning -> Game Loss -> Disqualification. Second offense of same infraction = next level up. DQs from accumulated infractions are NOT without-prize. Judge may repeat a penalty level before escalating (e.g., extra caution for inexperienced player).

## 1.0 Deck Problems

### 1.0.1 Illegal Decklist (decklist tournaments)
Illegal card count or illegal cards on decklist.
**Penalty: Warning.** Correct decklist to match actual deck if deck itself is legal. If both decklist and deck are illegal: **Game Loss**, 5 min to fix.

### 1.0.2 Illegal Main Deck (legal decklist, decklist tournaments)
Deck doesn't match decklist (misplaced cards, leftover cards from previous game, illegal count/cards).
**Penalty: Game Loss.** Restore deck to match decklist before next round. If judge is confident discrepancy is a decklist typo (e.g., Campground HG listed instead of Zoo HG in all-Gangrel deck), may fix decklist instead (Warning).

### 1.0.3 Illegal Main Deck (no decklist)
Illegal card count or illegal cards in deck.
**Penalty: Game Loss.** Remove illegal cards. If adding cards needed: only simple cards (Master Discipline, Forced Awakening, etc.), not counter cards. If removing cards: remove randomly.

## 1.1 Procedural Errors

### 1.1.1 Minor
Unintentional, slightly disruptive. E.g.: no pool tracking method, shuffling after opponent cut, holding cards below table.
**Penalty: Caution.** Upgrade to Game Loss if player cannot effectively continue.

### 1.1.2 Major
Unintentional, disruptive. E.g.: replacing sealed deck cards without permission, insufficient deck randomization.
**Penalty: Warning.** Upgrade to Game Loss if player cannot effectively continue.

### 1.1.3 Severe
Unintentional, extremely disruptive. E.g.: spilling drink on deck, unable to continue.
**Penalty: Game Loss.**

### 1.1.4 Misrepresentation
Unintentionally misplaying a card or rule. E.g.: Dread Gaze on own referendum, Frenzy during own turn, Art Museum without ready Toreador. If intentional: see 1.6 Cheating.
**Penalty: Caution.**

## 1.2 Card Drawing

### 1.2.1 Drawing Extra Cards
Placing card face-down to count draws (without looking) is NOT extra drawing. Apply penalty once per action/sequence.
**Penalty: Warning.** Correction: return known extra card (or random from hand) to deck and reshuffle. Exception: if another player knows part of deck order, return card to top without shuffling. Opponents may see any cards revealed by infraction. **Auto Game Loss** if too many cards drawn to correct.

### 1.2.2 Looking at Extra Cards
Dropping cards, flipping card while shuffling opponent's deck, revealing cards from misplay, seeing opponent's cards during random discard. Face-down counting is NOT looking. Apply once per action/sequence.
**Penalty: Caution.** Shuffle seen card back or return to appropriate location per 1.2.1 rules. **Auto Game Loss** if too many cards seen to correct or crucial strategic info revealed.

### 1.2.3 Improper Drawing at Start of Game
Drawing wrong number of cards for opening hand or uncontrolled region.
**Penalty:** Shuffle hand into deck, redraw opening hand with ONE FEWER card. Restore to normal hand size after every player has taken a turn. If extra crypt cards drawn: reduced to 3 uncontrolled vampires, draw 4th after every player has taken a turn.

### 1.2.4 Failure to Draw
Not drawing a required card.
**Penalty: Caution.** Draw back up to hand size.

## 1.3 Marked Cards
Assumes unintentional. If intentional: see 1.6 Cheating. Opaque sleeves: evaluate sleeves. Clear sleeves: evaluate card + sleeve.

### 1.3.1 No Pattern
Marks on cards/sleeves with no discernible pattern to card types.
**Penalty: Caution.**

### 1.3.2 Observable Pattern
Marks correlating with card types. E.g.: Jyhad-backed reactions in VTES-backed library, all copies of one card have bent sleeve corners.
**Penalty: Game Loss.**

## 1.4 Slow Play

### 1.4.1 Playing Slowly
Taking longer than reasonable for game actions. If intentional: see 1.6.2 Stalling.
**Penalty: Caution.** Judge may assign extra time sparingly.

### 1.4.2 Exceeding Pre-Game Time Limit
E.g.: still shuffling 3 min into round. If intentional: see 1.6 Cheating.
**Penalty: Caution** + 1-min time extension.

## 1.5 Unsportsmanlike Conduct
Applies even when player is not in an active game.

### 1.5.1 Minor
Disruptive to a person but no tournament impact. E.g.: inappropriate language, loudly demanding opponent be penalized.
**Penalty: Warning.**

### 1.5.2 Major
Disruptive to players, no delays/physical contact/significant emotional distress. E.g.: repeatedly calling judge over insignificant issues, disobeying tournament official, refusing to play.
**Penalty: Game Loss.**

### 1.5.3 Severe
Disruptive, causes delays, may include physical contact or significant emotional distress. E.g.: pulling chair causing injury, excessive belligerent arguing after final ruling.
**Penalty: Disqualification without Prize.**

## 1.6 Cheating
Intentional infractions for significant advantage.

### 1.6.1 Bribery
Offering inducements outside current game to change results. E.g.: cash/cards to throw a game.
**Exception (finals only):** Allowed if: (1) no outside incentives (no prize splitting), (2) all players in affected games agree.
**Penalty: Disqualification without Prize.**

### 1.6.2 Stalling
Intentionally playing slowly to exploit time limit. Includes idle activity for no purpose (e.g., Vast Wealth searches with no equipment left). Judge may add time to round (not exceeding time lost to stalling), must announce immediately.
**Penalty: Game Loss.**

### 1.6.3 Fraud
Intentionally misrepresenting rules, procedures, personal info, or tournament info. E.g.: fake name/VEKN number. Zero tolerance.
**Penalty: Disqualification without Prize.**

### 1.6.4 Collusion
Agreeing to alter/predetermine/illegally establish game results. E.g.: letting friend oust without resistance, coin flip to decide concession.
**Legal table talk/agreements require ALL of:** (1) no outside incentives, (2) no secret/out-of-game agreements, (3) no random winner selection, (4) no unsportsmanlike conduct or Code of Ethics violations.
**Penalty: Disqualification without Prize.**

## 2.0 Correction of Game State
Only judge may correct game state. Correction is IN ADDITION to penalty. Player must receive no benefit from infraction.
- **Few actions since error:** Back up to error point, correct, resume.
- **Many actions since error:** Leave game undisturbed or adjust (pool/blood levels) since players made decisions based on subsequent state.

Examples:
- Forgot contested card payment during master phase -> back up to untap, choose, continue
- Forgot contested card payment after lengthy complex turn -> make choice immediately, continue from current point
- Vampire illegally burned several turns ago -> return vampire to ready with 1 blood + 2 blood (simulating 2 hunt actions for missed turns)

## 2.1 Event Organization

### 2.1.1 Unexpected Drop
- 5-player table -> 4-player table
- 4-player table -> redistribute to legal table sizes
- Must conform to VEKN Tournament Rules 3.1.2 seating requirements
- If dropout causes invalid player count: event becomes unsanctioned. Between rounds, modifications allowed (judge plays, etc.) to maintain sanctioning
- Pre-round-1 drop causing unsanctioned: do NOT distribute prize support. Mid-event drops: distribute prizes normally. Submit event report noting what happened. Unsanctioned events don't count toward ratings.

### 2.1.2 Venue Interference
Venue forces modified round times. Event unsanctioned if any round < 2 hours AND any game ends on time. If all tables finish before time in a <2hr round: sanctioning retained. Note in event report.

## 3. Judge Ranks & Tests

### Ranks
- **Rulemonger**: Maintains rulebook, rulings DB, judge tests. Regular contribution expected. Appointed/relieved by VEKN Rules Director.
- **Judge**: Passed judge test with 80%+. Maintain rank by judging/organizing VEKN events or assisting Rulemongers yearly.
- **Judgekin**: Passed judgekin test (60%+) or judge test (50%+). Maintain rank by judging/organizing/participating in VEKN events every 6 months.

### Test Scores
| Rank | Judge Test | Judgekin Test |
|---|---|---|
| Judge | 80% | N/A |
| Judgekin | 50% | 60% |

Failed test: 6-month wait before retry. Leaking test content or cheating: rank revocation + test ban.

### Tournament Staffing Recommendations
- 25+ players (5+ tables): dedicated non-playing judge recommended (mandatory for Grand Prix/Championships per Tournament Rules 2.9)
- Head Judge should be Judge rank; assistants can be Judgekins
- Staffing: 1 judge per 50 players (1 HJ for 0-50, +1 assistant per additional 50)
