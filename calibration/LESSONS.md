# Calibration lessons — this repo's graded sessions

Operating heuristics distilled from the owner-graded corpus in `corpus/`. This file extends the
carried codex baseline, `references/strategy/calibration-lessons.md` (strategy lessons from the
2026-07 strategist runs, frozen upstream knowledge): read that file first, then this one. New
lessons land here — never in the carried file.

## Rules — sequencing

- **Walk the impulse, not just the windows.** A pass rotates the impulse onward around the
  table; a third party's out-of-turn window (Eagle's Sight) opens *before* the impulse returns
  to the acting Methuselah for the next modifier. "Was the window still open" is the wrong
  question when the real one is "whose impulse was it." (2026-08-25, eagle-sight entry.)
- **Answer the table repair too.** When the scenario describes out-of-order play (both sides
  played too fast), give the ruling *and* the remedy — roll the out-of-order card back to hand
  where possible. (Same entry.)

## Advice mode

- **Survey the slot before endorsing the named card.** The player names candidates; the answer
  owes them the competitors (Awe was fine; Scalpel Tongue and Closed Session were better). TWDA
  frequency of the named card is not a reason to stop looking. Corollary for vote decks:
  against opposing vote blocks, vote *denial* (cancel, lockout) beats vote *addition*.
  (2026-08-26, toreador-vote-push entry.)
- **A unique build-around starts with its fetch engine.** You won't run a dozen of a unique —
  name the Magic of the Smith-class density first, and note what the fetcher implies (an
  equipment toolbox around it). (2026-08-26, tremere-sword-of-nuln entry.)
- **Strikes don't stack.** One strike per round: before claiming combat synergy, check whether
  the cards compete for the strike slot (Theft of Vitae vs the Sword's strike). (Same entry.)
- **Verify crypt pairings against the grouping rule** — a single group or two *consecutive*
  groups, from the rulebook, every time. G6 pairs with G5 *or* G7, never both, never G4. (Same
  entry.)
- **Resolve name collisions before premise-checking.** A player's term may name a game concept
  (the Sabbat Path the new crypt follows), not the card that shares its name. Ground the
  referent, not the nearest card. (Same entry.)
- **A brew verdict needs the baseline and the survival test.** Compare against the archetype's
  established alternative (Carna Toolbox) and run the standard-answers check advice inherits
  from analysis: what does this do against S:CE (Telepathic Tracking for AUS decks) and
  Immortal Grapple? (Same entry.)
